### Library Book Store API (CRUD Operations)

The Library Book Store API is a backend application designed to manage a bookstore's inventory through fundamental CRUD (Create, Read, Update, Delete) operations. It provides a structured RESTful API to efficiently handle book records and maintain an organized digital library database.

The project is built entirely as a backend service using Node.js, Express.js, and MongoDB. It demonstrates a solid understanding of REST API design, server-side routing, database schema modeling using Mongoose, and handling HTTP requests and responses.

Key Features:

**Create (Add Books)**: Provides a `POST` endpoint to securely add new books to the database by sending data like title, author, publish year, and price.

**Read (View Inventory)**: Provides `GET` endpoints to fetch the complete list of available books or retrieve details of a specific book using its unique ID.

**Update (Edit Details)**: Includes a `PUT` endpoint that allows clients to modify existing book records to keep the inventory data accurate.

**Delete (Remove Books)**: Includes a `DELETE` endpoint with error handling to securely remove books from the MongoDB database when they are no longer available.

Tech Stack:

**Backend Environment**: Node.js

**Framework**: Express.js

**Database**: MongoDB & Mongoose

**Testing Tools**: Postman (for API testing)
